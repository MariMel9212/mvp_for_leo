# Banned AI Copy Slop Catalog & Production Replacement Matrix

> **Skill guard** — This document is a reference for the ux-editorial-copywriting skill.
> It contains intentional standard values and examples that the linter MUST skip.

---

## 1. The Anatomy of Modern AI Copy Slop

Unchecked LLMs produce three types of linguistic defects in user interfaces:
1. **Corporate bureaucratic stiffness** (verbal nouns, prepositional knots with *«для [сущ]»*, modal parasites).
2. **False marketing cheerfulness** (*«уникальный»*, *«бесшовный»*, *«успешно»*).
3. **Statistical AI triggers** (*«не просто X, а Y»*, parenthetical translation echoes, prompt scaffolding leakage).

## 2. Exhaustive Banned Vocabulary & BigTech Replacement Matrix

### 2.1 Category 1: Bureaucratic Knots & Prepositional Chains

| Banned Construct (RU) | The Linguistic Defect | Mandatory BigTech Replacement |
| :--- | :--- | :--- |
| *«Для предотвращения потери данных»* | Preposition + double verbal noun. | **«Чтобы не потерять данные»** |
| *«Для завершения регистрации»* | Heavy prepositional knot. | **«Чтобы зарегистрироваться»** |
| *«Осуществление настройки параметров»* | Double verbal noun hiding active predicate. | **«Настроить параметры»** |
| *«Произвести выполнение синхронизации»* | Three-word bureaucratic trap. | **«Синхронизировать»** |
| *«Произвести оплату заказа»* | Weak verb + noun. | **«Оплатить заказ»** |
| *«Совершить вход в аккаунт»* | Bureaucratic verbal noun. | **«Войти в аккаунт»** |
| *«В целях обеспечения безопасности»* | Pompous introductory clause. | **«Для защиты аккаунта»** |
| *«Носит обязательный характер»* | Passive bureaucratic phrasing. | **«Обязательно»** |
| *«Предоставление доступа пользователям»* | Obscuring actor and action. | **«Открыть доступ»** |

### 2.2 Category 2: Redundant Adverbs & Modal Parasites

| Banned Construct | The Core Defect | Mandatory BigTech Replacement |
| :--- | :--- | :--- |
| *«Успешно оплачено» / «Успешно сохранено»* | Redundant adverb. Actions cannot succeed "un-successfully". | **«Оплачено»** / **«Сохранено»** |
| *«Успешно выполнено»* | Meaningless placeholder. | State the exact completed entity: **«Профиль обновлен»** |
| *«Требуется пополнить счет»* | Impersonal modal parasite. | **«Пополните счет»** |
| *«Необходимо указать email»* | Bureaucratic constraint. | **«Укажите email»** |
| *«Недостаточно средств»* | Cold bureaucratic phrase. | **«Не хватает денег»** |
| *«Операция не может быть выполнена»* | Passive evasion of fact. | State direct reason: **«Платеж не прошел»** |

### 2.3 Category 3: False Enthusiasm & Marketing Hyperbole

| Banned Russian Term | Banned English Term | Mandatory Plain Replacement |
| :--- | :--- | :--- |
| **Уникальный** | **Unique** | State exact parameter or remove word entirely. |
| **Революционный** | **Revolutionary** | State factual software capability directly. |
| **Потрясающий / Невероятный** | **Incredible / Amazing / Delighted** | State operational status plainly without exclamation marks. |
| **Магия / Волшебный** | **Magic / Magical** | Explain automated trigger or background job plainly. |
| **Раскрыть потенциал** | **Unleash / Supercharge / Elevate** | State task capability: *"Настройте лимиты"* / *"Set limits"*. |
| **Оптимизируйте всё** | **Streamline your workflow** | Specify automated task: *"Формируйте отчеты автоматически"*. |
| **Бесшовный** | **Seamless** | *"Синхронизируется каждые 5 минут"*. |
| **Интуитивный** | **Intuitive** | Describe procedure plainly; remove word. |

### 2.4 Category 4: Sycophancy, Fake Apologies & Infantism

| Banned Construct | Why It Fails | Mandatory BigTech Alternative |
| :--- | :--- | :--- |
| *«Ой! Что-то пошло не так»* | Infantism and lack of diagnosis. | **«Не загрузилось: проверьте сеть и попробуйте снова»** |
| *«Простите нас, пожалуйста»* | Sycophancy during system outages. | **«У нас проблема — уже чиним. Попробуйте через 5 минут»** |
| *«Пожалуйста, введите ваш email»* | Weakens UI command in routine forms. | **«Введите email»** |
| *«Поздравляем! Вам одобрен кредит»* | Presuming user's emotional state. | **«Одобрили вам кредит»** / **«Кредит одобрен»** |
| *«Пожалуйста, подождите...»* | Sterile waiting filler without context. | **«Проверяем реквизиты — это займет до 30 секунд»** |

### 2.5 Category 5: High-Perplexity AI Detection Tells & English Calques

| Banned AI Construct / Calque | Why AI Flags It | Mandatory Human Replacement |
| :--- | :--- | :--- |
| *«Не просто X, а Y»* / *"Not just X, but Y"* | Artificial depth cliché; statistical tell of LLMs. | State exactly what X does plainly without drama. |
| *«Не только X, но и Y»* | Correlative conjunction overused by LLMs in every paragraph. | Connect with simple **«и»**: *«Быстро и без комиссии»*. |
| *«В современном мире»* / *"In today's fast-paced world"* | Primary opening tell of unedited LLM output. | Delete clause; begin with direct empirical fact. |
| *«Стоит отметить / Не секрет, что»* | Hollow rhetorical filler used to delay content. | State factual claim directly without preamble. |
| *«Давайте разберемся / Давайте посмотрим»* | Patronizing chatbot preamble (*"Let's dive in"*). | Delete preamble; start directly with the answer or step. |
| *«Будь то X или Y»* | Translated English *"whether it's X or Y"* cliché. | Name the concrete entities or omit. |
| *«Погрузитесь в мир...»* / *"Delve into"* | High-frequency GPT vocabulary trigger. | State concrete action: *«Изучите тарифы»*. |
| *«На ежедневной / регулярной основе»* | Literal calque of English *"on a daily/regular basis"*. | **«Каждый день»** / **«Регулярно»** |
| *«Пользовательский опыт»* (in customer UI) | Unnatural calque of *"user experience"* in user-facing copy. | **«Удобство работы»** or state the concrete improvement (*«Заказывать стало быстрее»*). |
| *«Был отправлен / Была создана / Было выполнено»* | Literal calque of English passive *"was sent / was created"*. | Active team verb (**«Отправили код»**) or short participle without *«был»* (**«Заявка создана»**). |
| *«Введите ваш пароль / Укажите ваш телефон»* | Possessive pronoun bloat calqued from English *"Enter your..."*. | **«Введите пароль»** / **«Укажите номер телефона»** |
| *«Таким образом... / Подводя итог...»* | Compulsive summary ending. | End cleanly on final operational action. |

### 2.6 Category 6: Typographical Slop, Ordinal Illiteracy & Punctuation Defects

| Banned Typographical Pattern | The Linguistic Defect | Mandatory Engineering Alternative |
| :--- | :--- | :--- |
| **Dots after UI abbreviations** (`тыс.`, `мин.`, `сек.`, `ч.`, `МБ.`) | Visual noise in interface containers. | Write without dots: `тыс`, `мин`, `сек`, `ч`, `МБ`, `ГБ`, `шт`, `руб`. |
| **Trailing dots on headers and buttons** | Visual full-stop blocking scanning. | Omit trailing dot: `### Настройки`, `<button>Сохранить</button>`. |
| **Suffixes on cardinal numbers** (`2-х дней`, `5-ти карт`, `3-х человек`) | Grammatical illiteracy in Russian. | Write cleanly: `2 дня`, `5 карт`, `3 человека`. |
| **Illiterate ordinal suffixes** (`1-ый`, `2-ой`, `3-ий`, `5-ого`, `2-ому`) | Violates Russian orthography (Gramota.ru / Rozental). | Use 1- or 2-letter suffixes: `1-й`, `2-й`, `3-й`, `5-го`, `2-му`. |
| **Ordinal suffixes on dates and years** (`25-го сентября`, `2026-го года`, `в 2026-м году`) | Redundant suffix when month or word «год» is present. | Write cleanly: `25 сентября`, `2026 года`, `в 2026 году`. |
| **Spaced en-dash or hybrid `с ...–...` in numeric ranges** (`10 – 15 мин`, `с 10:00–19:00`) | Breaks Russian range punctuation rules. | Unspaced en-dash (`10–15 мин`, `10:00–19:00`) or full prepositions (`с 10:00 до 19:00`). |
| **Straight quotes** (`"..."`) | English typewriter quotes in Cyrillic UI. | Use French guillemets (*«...»*) and inner „...“. |
| **Currency before amount in Russian** (`₽1 000`) | English currency convention in Russian. | Ruble symbol follows amount: `1 000 ₽`. |

## 3. The 3 Surgical Tests Before Sign-Off

1. **The Colleague Aloud Test**: Read the string aloud. If it sounds unnatural to say to a colleague sitting next to you, rewrite it.
2. **The "Чтобы" Test**: Check every occurrence of *«для»*. If followed by a verbal noun, rewrite into *«чтобы [глагол]»*.
3. **The 8-Word Economy Test**: Count words in each sentence. If > 8 words, split or prune.

# Leo

Лендинг подбора реабилитационных центров. Страница собрана по макету «Редизайн Leo» из Figma: шапка, первый экран с переключателем, цифры, блок «Когда стоит обратиться за помощью» и карточка «Как мы подбираем учереждения».

Сетка и размеры как у yasno.live: контейнер 540 / 720 / 960 / 1140, шапка 50px и 80px с 1200, навигация прячется в бургер до 1024, селект и кнопка на первом экране на всю ширину до 768.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:43123](http://127.0.0.1:43123).

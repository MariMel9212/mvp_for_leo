# СвойЦентр

Лендинг подбора реабилитационных центров по макету «Редизайн Leo». На странице шапка, первый экран, цифры, блок «Как работает подбор» и «Проверенные центры».

Текст набран Google Sans: Regular 400 и Medium 500, как в макете. Кнопки `#11ab09`, знак `#059000`.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:43123](http://127.0.0.1:43123).

# СвойЦентр

Лендинг «СвойЦентр» по кадру Desktop 1440. Сетка макета: 6 колонок, поле 120, промежуток 24. Фон `#FDFDFD`, шрифт Google Sans.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:43123](http://127.0.0.1:43123). Страница всех учереждений — [http://127.0.0.1:43123/uchrezhdeniya](http://127.0.0.1:43123/uchrezhdeniya).

## GitHub Pages

Сайт собирается в обычные файлы и выкладывается workflow `.github/workflows/pages.yml` при пуше в `main`. Адрес: `https://marimel9212.github.io/mvp_for_leo/`.

Репозиторий: https://github.com/MariMel9212/mvp_for_leo

В Settings → Pages → Build and deployment источник должен быть GitHub Actions. Ссылка появляется после зелёного workflow.

На бесплатном плане GitHub Pages работает только у публичного репозитория. У GitHub Pro приватный репозиторий тоже публикует страницу, и её можно открыть с телефона по ссылке.
